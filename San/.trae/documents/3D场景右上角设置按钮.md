# 在 3D 场景右上角添加“设置”按钮

## Context

用户希望在 3D 游戏场景（`SampleScene`）里像封面一样有一个设置入口，可以调节背景音乐 / 提示音音量。此前已把 `CoverMenu` 改造成封面与 3D 场景共用（打开设置时暂停 `HandleClick` / `PlayerMover`，关闭后恢复；无 `SceneFader` 时用 `SceneMusic.SetLocalVolume` 兜底；遮罩 `Dim` 拦截下层点击）。现在只差场景里实际存在一个按钮。

用户明确要求：“帮我建在右上角”，即由我直接在场景文件里创建，而不是让用户手动搭建。

## 现状调研结论

- `CoverMenu`（guid `c6a8ec5ad6ed827439fa547ea0004a1a`）在 `Awake` 中自动给 `settingsButton` 绑定 `OpenSettings`，所以场景里只需把 Button 组件填进 `settingsButton` 字段，`m_OnClick` 留空即可。
- `SampleScene` 已有 EventSystem，`CustomCursor` 强制 `cursorLockState = None`，3D 场景鼠标可点击 UGUI。
- 场景内所有根 Canvas 的 `m_SortingOrder` 都是 0；` 黑色画布`（GO 1958466811）是一个 order 0 的根 Canvas，子物体带 CanvasGroup（alpha 0、blocksRaycasts 0）用于黑幕渐隐，位于 `m_Roots` 较后位置。
- 已有 HUD 面板（` TaskHUDPanel`、` TaskHUDPanel (1)`）都锚定在左上角，右上角是空的。
- 项目字体：`Assets/字体/字体.ttf`，guid `2005793c52a8747409255568873bb95a`，主对象 `fileID: 12800000`。
- 计划使用的新 fileID 段 `2026112501`–`2026112515`，已确认场景中无冲突。

## 实现方案

### 唯一改动文件

`Assets/Scenes/SampleScene.unity`

### 1. 新增独立根 Canvas（Overlay）

- GameObject `2026112501`（`SettingsCanvas`，Layer 5）
- RectTransform `2026112502`（根，`m_Father: {fileID: 0}`，`m_Children` 含 Button 的 RT）
- Canvas `2026112503`：`m_RenderMode: 0`、`m_SortingOrder: -1`（渲染在所有 order 0 UI 之下、3D 场景之上，保证黑幕 / 手机聊天页 / 弹窗能盖住它，且不受同 order 排序不确定影响）
- CanvasScaler `2026112504`：`ScaleWithScreenSize`、参考分辨率 1920×1080、`matchWidthOrHeight 0.5`（与 `CoverMenu` 自建设置面板一致）
- GraphicRaycaster `2026112505`

### 2. 新增按钮 SettingsButton（Canvas 的子物体）

- GameObject `2026112506`
- RectTransform `2026112507`：anchor/pivot 均为 (1,1)，`anchoredPosition (-40,-40)`，`sizeDelta (170,60)` —— 右上角
- CanvasRenderer `2026112508`
- Image `2026112509`：内置 UISprite（`{fileID: 10905, guid: 0000000000000000f000000000000000}`）、`m_Type: 1`（Sliced）、深蓝半透明 `(0.10,0.28,0.45,0.85)`、`m_RaycastTarget: 1`
- Button `2026112510`：`m_Transition: 1`（ColorTint）、`m_TargetGraphic` 指向 Image、`m_OnClick.m_PersistentCalls.m_Calls: []`
- CoverMenu `2026112511`：
  - `settingsButton: {fileID: 2026112510}`
  - `quitButton: {fileID: 0}`
  - `font: {fileID: 12800000, guid: 2005793c52a8747409255568873bb95a, type: 3}`
  - `blockGameplayWhileOpen: 1`

### 3. 新增按钮文字 Text（Button 的子物体，铺满）

- GameObject `2026112512`、RectTransform `2026112513`（anchorMin 0,0 / anchorMax 1,1，offset 0）、CanvasRenderer `2026112514`
- Text `2026112515`：项目字体、`m_FontSize: 30`、`m_Alignment: 4`（居中）、白色、`m_RaycastTarget: 0`、水平/垂直 Overflow 各 1、`m_Text: "\u8bbe\u7f6e"`（设置）

### 4. 场景根列表

在 `--- !u!1660057539 &9223372036854775807` 的 `m_Roots` 末尾追加：

  - {fileID: 2026112502}

## 验证

1. 打开 Unity 进入 `SampleScene` 的 Play 模式，右上角应出现“设置”按钮。
2. 点击按钮：弹出设置面板（两根滑条），此时第一人称移动 / 场景点击被暂停。
3. 拖动“背景音乐”滑条：`SceneMusic` 音乐音量实时变化；拖动“音效 / 提示音”影响 `AudioVolumeController`。
4. 点“关闭”：面板消失，移动与场景点击恢复。
5. 触发黑幕 / 打开手机聊天页：按钮应被盖住（`sortingOrder -1`）。

## 注意

- 不改动 `CoverMenu.cs` 等脚本（功能已就绪）。
- 按钮位置可在 Scene 视图中直接拖动 `SettingsCanvas/SettingsButton` 微调。
